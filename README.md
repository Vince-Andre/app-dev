# House of the Dragon

**House of the dragon** is a fantasy drama television series. It is a prequel to *Game of Thrones*.

## Key elements of the show
- Political intrigue and succession crisis
- Massive dragon battles
- Deep, morally gray characters

### Favourite Quote
> "History does not remember blood, It remembers names."
